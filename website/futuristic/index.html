[02 / ABOUT]

Sowa is a standalone, experimental distribution for servers and headless environments. It builds an x86_64 toolchain, kernel, userspace, live media, and signed package repository without installing files into the host system.

It is intentionally compact, legible, and old-school. There is no fixed release cycle and no promise of backward compatibility—just an honest system you can inspect, modify, and rebuild.

[ source on github ] [ read the manual ] [ gpl-3.0-or-later ]

  • + Docker + GNU Guix available
  • + reproducible, pinned build inputs

[03 / QUICKSTART]

  1. 01

    Download + verify

    Keep the image and checksum file together.

    sha256sum -c sowa-0.1-x86_64.iso.sha256
  2. 02

    Test in QEMU

    Give the live system 2 GiB of memory and a serial console.

    qemu-system-x86_64 -m 2G -cdrom sowa-0.1-x86_64.iso -nographic
  3. 03

    Install from live

    Log in as root on the local console, then launch setup.

    sowa-setup
!
