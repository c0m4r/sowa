Welcome to the Sowa Linux home page

Sowa is a small, experimental Linux distribution for servers and headless machines. It is built from source, uses its own SysV-style init, and tries to keep the whole system small enough to understand.

== WHAT IS SOWA? ==

Sowa builds an x86_64 toolchain, kernel, userspace, live ISO, installable disk images, and a signed binary package repository without installing files into the host system. It is aimed at power users who miss small Unix-like systems and do not want systemd. 

[+] custom System V-style init and service framework
[+] sowa-pkg package manager with a signed package repository
[+] live media for both legacy BIOS and UEFI
[+] declarative network configuration through "nic"
[+] SSH enabled with key-only root access by default
[+] Docker and GNU Guix available as optional packages
[+] pinned source archives and per-package file ownership
[+] no fixed release cycle, update model, or compatibility promise

If you want a polished desktop, this is not it. If you want to build a machine from the ground up and see what every part is doing, you may be in the right place.

== QUICK START ==

1. Download and check the ISO

$ sha256sum -c sowa-0.1-x86_64.iso.sha256

2. Boot it in QEMU

$ qemu-system-x86_64 -m 2G -cdrom sowa-0.1-x86_64.iso -nographic

3. Install from the live system

# sowa-setup

The live console logs in as root without a password. Remote root login stays disabled until you install an SSH key. Read the installation guide before writing to a real disk.

!!! WARNING: THE INSTALLER CAN ERASE AN ENTIRE DISK. KEEP BACKUPS. !!!
